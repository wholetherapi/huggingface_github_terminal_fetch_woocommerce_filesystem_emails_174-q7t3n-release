# Open Release Policy

## 4.2 License selection for derived dataset releases

Every published release must carry exactly one license identifier.

1. A release license is inherited, not invented. It must come from a contributor
   whose material is actually included in this release: a direct data source of
   the released records, or a model used to synthesize natural-language content
   in the release.
2. Only content that is part of this release can supply a license. Catalogue or
   registry entries that did not contribute records to this release are not
   license sources.
3. Read the license that actually governs the contributed material. A license
   that applies only to other artifacts does not extend to the released dataset
   and must not be reused.
4. If more than one candidate license applies, choose the one whose terms are
   most permissive for derivative and secondary use. Attribution-only terms are
   more permissive than share-alike, non-commercial, or no-derivatives terms.
5. Record the chosen SPDX-style identifier in the dataset card and announce it
   on the release issue.
