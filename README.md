# SignalForge Customer Feedback Corpus — Release v4

SignalForge v4 is a curated multilingual corpus of customer-support conversations
assembled for public research release.

## Provenance

The release merges excerpts from several upstream corpora. Assistant-style
responses were synthesized with SynthLab Atlas 7B. The full contributor ledger is
kept at `provenance/sources.json`; the open-release licensing policy is in
`release_policy.md`.

## Structure

- `provenance/sources.json` — contributor ledger (one record per catalogued source)
- `release_policy.md` — open-release licensing policy
- `upstream/` — mirrored cards for upstream data sources
- `model/` — mirrored card and license for the synthesis model
- `data/` — release shards (not included in this staging repository)
